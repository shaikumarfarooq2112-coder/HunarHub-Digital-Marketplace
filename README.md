# HunarHub

## Empowering Local Artisans

HunarHub is a full-stack web application that connects local artisans
and entrepreneurs with customers through an online marketplace.

The platform allows users to discover handmade products, search and
filter products, view product details, place orders, manage profiles,
and add products.

## Features

- User Registration and Login
- JWT Authentication
- User Profile
- Product Listing
- Product Search
- Category Filtering
- Product Details
- Add Product
- Order Management
- Order Status
- Customer Reviews
- Responsive Homepage
- Featured Products
- Artisan Information
- Statistics Section
- Testimonials
- Contact Section
